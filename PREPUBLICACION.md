# Lista pendiente antes del lanzamiento real

Esta entrega es una **demo pública opcional**, no una web corporativa definitiva.

1. Confirmar identidad AB / ALS y antecedentes marcarios.
2. Confirmar servicios que la empresa prestará efectivamente, profesionales habilitados y alcance técnico.
3. Sustituir imágenes IA por fotos reales autorizadas; separar trabajos del equipo ejecutados para terceros de obras contratadas por la empresa.
4. Añadir medios de contacto reales y probar el envío de formularios con backend, servicio tercero o enlace `mailto:` verificado. GitHub Pages no ejecuta un backend propio.
5. Añadir políticas de privacidad acordes a la recolección de datos (si se implementan formularios/analítica).
6. Eliminar `<meta name="robots" content="noindex, nofollow">` de `index.html` **solo** cuando el contenido sea aprobado para su indexación.
7. Incorporar URL absoluta de dominio verificado como `rel=canonical`, `og:url`, `og:image` absoluta y un `sitemap.xml` con URL definitiva. No inventar hoy ninguna URL.
8. Ajustar la descripción SEO con la oferta validada. Evaluar JSON-LD `Organization`/`LocalBusiness` solo con datos reales.
9. Crear/verificar Google Search Console y ficha de Google Business Profile cuando corresponda.
10. Probar Core Web Vitals / Lighthouse en URL final, Safari iOS, Chrome Android, tablet y escritorio.
11. Revisar accesibilidad: navegación con teclado, contraste, usuarios con movimiento reducido, zoom 200%, VoiceOver y TalkBack.
12. Comprobar HTTPS del dominio final, redireccionamientos y titulares de los activos digitales.

La versión actual incluye SEO técnico básico, pero **no puede garantizar posicionamiento** ni sustituye el contenido definitivo y su validación.
